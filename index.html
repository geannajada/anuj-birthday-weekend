How to use, share & publish

Pick one option in each restaurant group. Choose Saturday lunch or dinner, then switch to Final itinerary for a focused view. Unresolved choices remain visible. Download HTML saves a portable copy with your current selections and checklist progress. Print / PDF includes all three days in the current mode.

For iPhone, use the published GitHub Pages link in Safari. Local HTML file previews may not run interactive features. Share selections creates a URL snapshot once hosted; it does not change anyone else’s existing link.

  1. Create or open your GitHub repository and upload this file as index.html at the repository root. Commit the upload.
  2. Open Settings → Pages → Build and deployment. Choose Deploy from a branch, then main and / (root), and Save.
  3. Wait for GitHub’s Pages build, open the published address shown there, and test it in Safari. Use Share selections from the published page.
  4. To update the guide, replace index.html in the same repository and commit. Re-share a new selections link when your choices change.
